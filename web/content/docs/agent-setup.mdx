OpenSEO connects your agent to live SEO data through MCP. Skills give it reusable workflows for keyword research, audits, competitor research, and other SEO tasks.

## Set up your agent

Copy this prompt into Claude Code, Claude Cowork, or another agent. It asks your agent to use its supported installation method and guide you through any steps you need to do yourself.

<AgentPrompt kind="setup" />

Approve the OpenSEO sign-in in your browser when prompted. Once setup is complete, ask your agent to use **SEO Coach** to help you choose what to do next.

You can also copy this prompt from [Agent setup in OpenSEO](https://app.openseo.so/ai). For a self-hosted instance, use its Agent setup page so the prompt includes your own server address.

Prefer to set it up yourself? Follow the instructions for your agent below. If the setup prompt already completed installation, skip to [Update your skills](#update-your-skills).

### Claude Code

Run inside Claude Code to install MCP and the public SEO skills:

```text
/plugin marketplace add every-app/open-seo
/plugin install openseo@openseo
```

If Claude asks you to activate the plugin, run `/reload-plugins`. Follow the sign-in prompt, then try `/openseo:seo-coach`. See the [Claude Code plugin guide](/docs/claude-code-plugin) for troubleshooting.

### Claude Cowork

Install the OpenSEO plugin from **Customize → Plugins → Add marketplace → Add from a repository** with `https://github.com/every-app/open-seo`. It adds MCP and the public SEO skills. See the [Claude Cowork steps](/docs/claude-code-plugin#install-in-claude-cowork) for details and the Free plan option.

### Claude web and other agents

Follow the [MCP connection guide](/docs/mcp), then install skills through your agent's supported skill manager. Claude manages custom skills under **Customize → Skills**. On a paid Claude plan, the [OpenSEO plugin](/docs/claude-code-plugin#install-in-claude-cowork) installs both in one step.

For agents using the skills CLI, choose public OpenSEO skills interactively:

```bash
npx skills add https://github.com/every-app/open-seo/tree/main/plugins/openseo/skills
```

Choose the current agent and your preferred installation scope. Skip this if the OpenSEO plugin already supplies your skills. See [manual skill setup](/docs/skills/setup) for other options.

## Update your skills

When OpenSEO releases improved skills, update the copies installed in your agent. Updating the MCP connection alone does not update those files.

Paste this prompt into the agent where you use OpenSEO. It asks the agent to check how the skills were installed and preserve your connection settings and personal edits.

<AgentPrompt kind="update" />

To update manually, use the method that matches your installation below.

### Update the Claude Code plugin

Run inside Claude Code:

```text
/plugin marketplace update openseo
/plugin update openseo@openseo
/reload-plugins
```

You can enable automatic updates in `/plugin` → **Marketplaces** → **openseo** → **Enable auto-update**. Third-party marketplaces have this off by default. Reload when Claude prompts you to activate an update. See [Claude's plugin update documentation](https://code.claude.com/docs/en/discover-plugins#configure-auto-updates).

### Update skills installed with the skills CLI

List your installations, then update the OpenSEO skills by name. For example:

```bash
npx skills list
npx skills update seo-coach seo-audit
```

Use the names you actually installed and choose the same project or global scope. Pass `-g` for global skills or `-p` for project skills. Back up personal edits before updating. Run the setup command to select any newly added workflows separately. See the [skills CLI documentation](https://github.com/vercel-labs/skills#skills-update).

### Update manually copied skills

Use the update prompt above.

For manually copied skills, compare your installed copies with the [public OpenSEO skill folders](https://github.com/every-app/open-seo/tree/main/plugins/openseo/skills). Preserve personal edits and replace the complete skill folder, including supporting files. Use your agent's skill manager for uploaded skills, such as Claude's **Customize → Skills**.

After updating, reload the skills or start a new session if needed. Ask the agent to confirm it can find the updated OpenSEO skills before starting your next SEO task.
